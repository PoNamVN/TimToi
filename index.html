Deterministic 8-Stage Production Lifecycle

Every Short progresses through structured quality checkpoints stored in an ACID-compliant local SQLite queue.

01

Topic Research & Consensus Validation

Agent 02 conducts scientific verification, confirming primary sources and drafting counter-intuitive science hooks.

02

Educational Scripting & Analogy Engineering

Agent 03 produces an 8-beat viral educational script strictly calibrated for 30–45 second viewing with precise word pacing.

03

Fact-Checking Gate

Agent 04 cross-checks every single script claim against the research dossier. If any claim lacks scientific grounding, the job is paused.

04

Visual Scene & Storyboard Direction

Agent 05 establishes shot-by-shot visual timing, character mascot reactions, and educational infographic placements.

05

Local Audio Synthesis & Asset Preparation

Agent 06 synthesizes crystal-clear Vietnamese speech on-device with VieNeu-TTS and verifies all graphic assets.

06

60fps Compositing & Rendering

Agent 07 drives local FFmpeg compositing, assembling master vertical video with clean visual styling and aligned subtitles.

07

Automated Quality Assurance

Agent 08 validates audio loudness, video duration, absence of visual artifacts, and generates a cryptographic SHA-256 fingerprint.

08

Human Editorial Review & Multi-Platform Release

The creator inspects the video preview in Telegram and explicitly selects publishing to YouTube, TikTok Inbox, or both.

Responsible AI & Platform Compliance

TikTok Developer API Standards

Our TikTok integration strictly conforms to official TikTok Developer documentation and policies:

  • OAuth 2.0 with PKCE: Local authentication using state tokens and code verifiers.
  • Mandatory AIGC Transparency: All videos uploaded transmit the official is_aigc: true metadata flag.
  • Upload to Inbox Protection: Clearly distinguishes creator draft uploads from live public broadcasts.
  • No Scraping or Bot Automations: Uses only official HTTPS REST API endpoints. Zero reverse engineering or browser scraping.

Local Privacy & Data Security

Tim Toi Studio operates as a local utility on the creator's machine:

  • Local Token Storage: OAuth access and refresh tokens are stored exclusively on the local Windows filesystem in protected directories.
  • Zero Cloud Telemetry: No user credentials, video files, or telemetry are collected or uploaded to any intermediate cloud database.
  • Instant Revocation: Creators can revoke all permissions at any time via TikTok or by deleting local tokens.
  • Storage Janitor: Automatically quarantines temporary assets while protecting verified master outputs.
